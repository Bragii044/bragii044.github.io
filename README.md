# Tyler Wickstrom: author homepage

Source for https://wickedtricks.github.io, published with GitHub Pages from the `main` branch.

- `index.html`: the whole page (styles and a small script are inline)
- `img/`: headshot, cover, full cover wrap, and the link-preview image
- `fonts/`: self-hosted Cinzel, EB Garamond and Archivo (SIL Open Font License)

Events hide themselves automatically after their end time (`data-ends` on each `.event`).
